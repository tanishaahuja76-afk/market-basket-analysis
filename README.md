# Market Basket Analysis using Apriori Algorithm

## Executive Summary
This project analyzes retail transaction records to identify purchasing patterns, item associations, and cross-selling opportunities using the **Apriori Algorithm**.

## Key Visualizations
- **Top Sold Products**: Identifies revenue drivers and high-frequency inventory items.
- **Geographic Distribution**: Highlights primary customer markets.

## Business Recommendations
1. **Product Bundling**: Pair high-lift items together on product pages.
2. **Promotional Offers**: Discount low-margin secondary items when purchased with high-volume anchors.
3. **Checkout Placement**: Recommend associated impulse items during checkout.

## Technical Stack
- Python (Pandas, NumPy, Matplotlib, Seaborn, Mlxtend)
- Apriori Algorithm & Association Rules
